Software Engineering & Design

Watch The Weight Fall Off • Android Application

This enhancement focuses on improving the design, functionality, and user experience of my Watch The Weight Fall Off Android application. The project demonstrates how an existing application can be redesigned and expanded while maintaining its original purpose.

Project Overview

Watch The Weight Fall Off was originally created as an Android weight-tracking application. For my CS 499 capstone, I returned to the application and enhanced its software design and user interface to create a cleaner and more useful experience for the user.

Enhancement Highlights

The enhanced version improves how weight progress is presented to the user. I added a circular progress display and additional progress calculations to make important information easier to understand at a glance. These changes also gave me an opportunity to improve the organization and functionality of the existing code.
