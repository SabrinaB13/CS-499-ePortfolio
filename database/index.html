Database Development

Watch The Weight Fall Off • Android Application

This enhancement focuses on expanding the application's SQLite database and using stored weight data to support additional functionality, including milestone tracking and progress recognition.

Project Overview

Watch The Weight Fall Off uses a local SQLite database to store information needed by the application. For my CS 499 database enhancement, I expanded the existing database functionality to better support the user's weight-tracking progress and new application features.

Enhancement Highlights

I enhanced the database design by adding milestone functionality that works with the user's stored weight information. The application can recognize progress milestones as the user loses weight and display a milestone notification. This required changes to the SQLite database structure, database helper logic, data-access functionality, and the user interface.
